6. Design Notes

Port Prefix

ServerPortBadge now shows :3000 instead of 3000. The colon prefix instantly signals "port number" — avoids ambiguity with other numeric values that might appear on the card.

Bidirectional Animation

Transitions work in both directions: running pill → collapsed circle AND collapsed circle → running pill (when re-running a command). CSS transition on width, padding, opacity, and color handles both. Storybook stories should cover both directions with play tests.

Animation Timing

Width/padding: 300ms ease-in-out. Color/background: 200ms ease-in-out. Text/spinner opacity: 200ms (fades out before collapse completes). Icon opacity: 150ms with 100ms delay (fades in after collapse starts).

Styling Pattern

Uses --badge-color CSS variable + resolveBadgeStyleClass(), identical to PriorityBadge and ServerPortBadge. All three badge styles (A/B/C) work via the same color-mix pattern.
