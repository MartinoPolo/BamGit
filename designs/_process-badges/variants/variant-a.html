5. Design Notes

Styling Pattern

Uses --badge-color CSS variable + resolveBadgeStyleClass(), identical to PriorityBadge and ServerPortBadge. All three badge styles (A/B/C) work via the same color-mix pattern from badge_style_utils.ts.

Icon Choices

Passed: circle-check (existing). Failed: circle-x (existing). Timeout: clock — clock face reads well at 12px, strong timeout association. Stopped: square — universal stop/stop-media icon, rounded corners for softness.

Restart Count

Rendered as plain monospace text 2/3 appended after the command name in the running pill. Slightly dimmed (opacity: 0.7) to keep focus on the command name. No sub-badge — keeps the pill compact.

Stale Behavior

opacity-40 on CommandResultBadge only. ServerPortBadge stays full opacity — the server is still running regardless of file changes. Same stale treatment already implemented in the existing component.
