DESIGN NOTES
Button Styling

All buttons match the real Button component: rounded-md (not sm), ghost variant uses bg-transparent hover:bg-surface-2, icon-sm is var(--size-control-sm) (26px), active:scale-96. Footer buttons use variant-secondary with visible border.

Scroll Indicators

Pills are positioned on a wrapper div outside the scroll container using position: absolute. They do not scroll with content. Bottom pill hides when scrolled to bottom. Top pill hides when at top. Click either to jump to that edge.

Port Badge in Header

Reuses existing ServerPortBadge component with :port format. Shown only when a port is detected (dev-server commands). Placed after the issue identifier in the title bar. Not shown for non-server commands like check:all.

Single Copy Button

One copy button in the footer toolbar (removed duplicate from title bar). Uses secondary variant with visible border for discoverability. Same navigator.clipboard + 2s check pattern as CodeBlock.

Dialog Styling

Matches Dialog.Content: rounded-xl, border-border, bg-surface, shadow-lg. Overlay at 72% opacity (matching Dialog.Overlay), no blur per DECISIONS.md.

Auto-scroll Toggle

Toggle button with aria-pressed. Active state uses primary tint background + primary border. Toggling off pauses auto-scroll; toggling on resumes and jumps to bottom. Scrolling up auto-disables the toggle.
