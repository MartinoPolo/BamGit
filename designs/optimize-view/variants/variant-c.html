Explanation

Claude is reading into directories that contain no useful source files — only build artifacts, dependency trees, and version-control internals. These reads inflate context size significantly before any meaningful work begins.

Offending directories found across 8 sessions:

node_modules/ ×9 .git/ ×6 dist/ ×4 build/ ×2
Recommended Fix

Add a .claudeignore file at the project root. Claude reads this file on startup and skips all listed paths during glob and read operations.

.claudeignore
# Auto-generated by Grovekeeper — junk directory exclusions
# Prevents Claude from reading build artifacts and deps

Why This Matters
Context window space is finite. Every token spent on node_modules/ internals is a token unavailable for your actual source code. At an average of 7,200 wasted tokens per session, this single fix can push your effective context headroom up by ~12% — keeping longer tasks coherent without mid-session truncation.
