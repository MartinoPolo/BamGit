Description

Implement a drag-to-split tab model for the bottom panel. Each panel maintains its own independent tab bar. Users can drag any tab from one panel's tab bar to another to move it between panels. Dragging a tab to the edge of a panel (left, right, top, or bottom) creates a new split in that direction with the dragged tab as the initial content.

The status bar should include a miniature wireframe diagram showing the current panel arrangement. Right-clicking any panel divider opens a context menu with preset layout options (single, side-by-side, quad, left-merged, etc.) for quick layout switching.
