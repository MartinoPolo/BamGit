Description

Add a small layout-icon button to the bottom panel toolbar that opens a floating popover grid showing all 7 layout presets as visual thumbnails. The selected layout is highlighted with a primary-color ring. Each preset thumbnail renders the panel arrangement using minimal div geometry (no external assets). Choosing a preset closes the popover and transitions the panel split.

Panels must each maintain an independent tab bar (36px height) and support a minimum width of 200px. The resizer between panels shows a drag handle on hover with a 3px indicator bar that turns primary-green on hover.
