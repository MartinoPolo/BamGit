design notes
Invisibility at rest

The component inherits all color and weight from its parent. In a workspace card footer at 10.5px, it reads identically to the surrounding muted text — no color shift, no underline. Interactivity is hidden until the user explores.

Dotted over solid

A dotted underline (1px dotted --foreground-muted) signals "enriched text" rather than a standard anchor link. Solid underlines imply external navigation; dotted implies in-app drill-down. This matches conventions used in spreadsheet formula references and IDE type hints.

Tooltip as primary label

"View usage details" appears only on hover — not as a persistent label. This keeps the data dense without cluttering stat rows with repeated navigation affordances. The tooltip appears above to avoid blocking adjacent values in footer rows.
